## 一、Dorf Ketal Tyzor® 有機鈦酸酯與鋯酸酯系列 (共 24 份)


### 1.1 原理機制 (Principles)

#### 01. 鈦（鋯）酸酯作為交聯劑反應機制
- **檔案編號**：`TYZ-01`
- **實體路徑**：`techdatadb/2.Tyzor/1.原理/鈦（鋯）酸酯作為交聯劑.pdf`
- **適用領域**：塗料、印刷油墨、膠黏劑、聚合物改性
- **吸睛摘要**：油漆與油墨的「成膜固化加速器」，藉由鈦/鋯中心與樹脂中的羥基、羧基迅速架橋形成三維網絡，低溫即可固化，大幅強化耐水、耐刮與耐溶劑表現。
- **四大核心重點**：
  1. 加速常溫或低溫烘烤固化速度，顯著縮短塗膜完全乾燥與成膜週期。
  2. 與高分子官能基形成緊密三維立體網絡，顯著提升耐水、耐水煮蒸煮與高溫熱穩定性。
  3. 增強漆膜表面鉛筆硬度（提升 1~2H），賦予卓越的耐摩擦與耐刮傷物理性能。
  4. 大幅提升塗層耐化學品侵蝕與耐溶劑（如 MEK 擦拭次數突破 200 次）保護力。

#### 02. 鈦（鋯）酸酯作為催化劑反應機制
- **檔案編號**：`TYZ-02`
- **實體路徑**：`techdatadb/2.Tyzor/1.原理/鈦（鋯）酸酯作為催化劑.pdf`
- **適用領域**：聚酯合成、增塑劑製造、酯化與酯交換反應
- **吸睛摘要**：聚酯與增塑劑合成的「綠色高效催化劑」，徹底告別有毒有機錫，能在高達 280°C 高溫下保持極高催化活性，反應快、收率高且不易發黃變色。
- **四大核心重點**：
  1. 100% 不含有機錫化合物，完全符合歐美 FDA 食品接觸與 REACH 環保法規。
  2. 顯著降低反應活化能，縮短聚酯與直接酯化反應時間達 25%~40%，大幅節省能耗。
  3. 在 280°C 高溫縮聚下依然維持極高催化活性，單體轉化率高且副產物極少。
  4. 專用型號（如 Tyzor 436）具備超低黃變特性，產出的聚酯產品清澈透亮。

#### 03. 鈦（鋯）酸酯作為表面改性反應機制
- **檔案編號**：`TYZ-03`
- **實體路徑**：`techdatadb/2.Tyzor/1.原理/鈦（鋯）酸酯作為表面改性.pdf`
- **適用領域**：Sol-Gel 鍍膜、金屬防腐、玻璃改性、無機填料包覆
- **吸睛摘要**：玻璃、金屬與顏料表面的「奈米防護衣」，透過溶膠-凝膠（Sol-Gel）水解縮聚形成均勻緻密的金屬氧化物保護層，耐高溫、耐腐蝕且抗劃痕。
- **四大核心重點**：
  1. 利用 Sol-Gel 工藝在基材表面沉積均勻連續的金屬氧化物（TiO2 / ZrO2）奈米薄膜。
  2. 賦予底材表面卓越的耐高溫熱氧化防護與長效耐腐蝕隔離屏障。
  3. 提高表面耐刮傷與抗磨損硬度，並可依配方需求調控表面親水或疏水特性。
  4. 有效增進無機填料（如碳酸鈣、高嶺土）與有機高分子基質間的偶合潤濕相容性。

#### 04. 鈦（鋯）酸酯提高附著力反應機制
- **檔案編號**：`TYZ-04`
- **實體路徑**：`techdatadb/2.Tyzor/1.原理/鈦（鋯）酸酯提高附著力.pdf`
- **適用領域**：油墨印刷、金屬底漆、塑膠塗裝、封裝膠黏
- **吸睛摘要**：難附著底材的「化學雙面膠」，分子兩端分別鍵合金屬/玻璃無機表面與有機樹脂塗層，搭建堅固分子橋樑，牢牢抓緊基材不脫落。
- **四大核心重點**：
  1. 在難黏基材（PP、PE、PET、金屬、玻璃）介面搭建化學鍵橋樑，顯著提升密著強度。
  2. 大幅提高塗層在高濕度、鹽霧浸泡及冷熱循環環境下的乾濕態附著耐久性。
  3. 顯著提升油墨在包裝塑膠薄膜上的耐膠帶剝離測試（Scotch Tape Test）堅牢度。
  4. 促進漆膜硬度提升，有效防止塗層邊緣在加工衝壓或折疊時發生翹皮與分層脫落。

  2. 在極端嚴苛的高速摩擦循環測試中，提供塗層最高等級的耐磨防刮損保護。
  3. 顯著降低表面張力與滑動阻力，耐劃傷鉛筆硬度與鋼絲絨擦拭表現卓越。
  4. 耐溫性極高（熔點 > 300°C），在高溫工業卷材與特種防護塗料中結構穩定。
